# Social Media Tools: Case Study

Tools that help social media managers and their clients make content faster, built under my brand Seven Solace Co.

**Status:** in discovery and early build. The code will stay private since these are paid tools. This page follows the product as it grows.

## The problem

I've worked as a freelance social media manager and brand strategist for 2.5+ years, including for independent music artists. Most of the job isn't the creative part. It's the work around it: planning, organizing ideas, keeping content consistent, and doing the same setup over and over for every post and every client.

**The job to be done:** help social media managers spend less time on the busywork and more time on content that performs.

## Who it's for

- Freelance social media managers juggling several clients
- Small brands and creators who run their own social media

## Research so far

- **Competitive research:** I did a deep review of Busy Blooming HQ, an existing resource for social media managers, to see what works and where people still lose time.
- **Gaps and frameworks:** from that research I pulled out the product gaps and the content strategy frameworks the tools will be built around.
- **My own experience:** 2.5+ years of client work shows where the hours actually go.

## Product decisions

| Decision | Why |
| --- | --- |
| Free versions alongside paid tools | Free tools build a community around the brand, and paid tools serve clients who need more |
| Built for social media managers first | They feel the pain every day and across many accounts, so the value is clearest |
| Start small, one tool at a time | Ship the tool that saves the most time first, then learn from real use |

## Next

1. Pick the first tool to build from the research gaps.
2. Test it with a few social media managers.
3. Launch the free version, then the paid version.
